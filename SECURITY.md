# Security Policy 🔒

## Supported Versions

Only the latest major version of **EssaLab.Zid** receives security updates.

| Version | Supported |
| :--- | :--- |
| 1.x.x | ✅ Yes |
| < 1.0 | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **EssaLab.Zid**, please do **NOT** open a public issue.

Instead, please send an email to **security@essalab.com** (or contact the repository maintainer directly via GitHub). 

### What to Include
- Detailed description of the vulnerability.
- Proof-of-concept (PoC) code or steps to reproduce.
- Potential impact of the issue.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a timeline for resolving the issue and keep you updated throughout the process.
